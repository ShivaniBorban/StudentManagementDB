# Student Management Database (SMDB)

A MySQL-based project to manage student records, departments, courses, and enrollments.

### Technologies
- MySQL
- MySQL Workbench
- SQL

### Features
- Student record management (CRUD)
- Department and course management
- Student enrollment tracking
- Marks and grades management
- SQL Joins and Aggregate Functions

### Database Tables
1. Students
2. Departments
3. Courses
4. Enrollments
